# Encoded questions and much-more interactive responses
Using different encoding changes the responses.

Using the "default" encoding, by just typing into MAGiE and then recording
the text to the card will act just like typing on the terminal.

But if players use the binary format to encode questions, they will get
very different responses. These interactions all use Alpha-Length, A=1 encoding.
The screen will display simple responses, but the terminal will dispense cards
with the given responses.
