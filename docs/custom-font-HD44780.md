CUSTOM HD44780 FONT
========================

"HD44780" refers to some LCD display controller. It's the source of the HD44780 font which was used all over the place on little dot-matrix displays (both LCD and VFD).

The original font only had _[some number of]_ characters, and included some Japanese ones. But, the modern fonts support anything in Unicode, but they don't have character glyphs. On Fontstruct[1], I have cloned one of those HD44780 fonts and added just a few glyphs. Today (2026-08-11), I added the eject symbol: ⏏, and also some others that I encountered along the way (just for fun and practice).

I named the current version of the font with the date. It can be found at [public/fonts/hd44780a00-5x8-20260811.ttf](public/fonts/hd44780a00-5x8-20260811.ttf)
