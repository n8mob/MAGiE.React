BIT SOUNDS
=========================

# Phase 1
A bit-toggle sound

# Phase 2
Different sounds for toggling bits off and on

# Phase 3
Different sounds according to the following:

|                        | On -> Off | Off -> On |
|------------------------|-----------|-----------|
| Correct -> Incorrect   |           |           |
| Incorrect -> Correct   |           |           |
| Unguessed -> Correct   |           |           |
| Unguessed -> Incorrect |           |           |
